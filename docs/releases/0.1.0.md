# Writing Workbench 0.1.0

BRAT 설치·검증을 위한 첫 개발 릴리스입니다. 프로덕션 인수 검증은 진행 중입니다.

## 사용 흐름

- 대화로 주제와 관점을 찾는 한 질문씩 인터뷰
- 개요 정리 후 사용자가 직접 작성하는 초안
- 전체 진단과 문장별 수정 제안, 개별 수락·거절
- Claude Code / Codex CLI 전환과 공통 맥락 유지
- 요청별 외부 검색, 참고 자료·출처, 승인 기반 문체 원칙
- 작업 사본 보관, 원고 저장 충돌 감지, 이전 원고 복원
- LinkedIn 데스크톱·모바일 예상 미리보기

## BRAT 설치

BRAT의 **Add beta plugin**에 아래 저장소를 입력하고 **0.1.0**을 선택하세요.

`logos1012/obsidian-writing-workbench`

플러그인을 켠 뒤 설정에서 Claude Code 또는 Codex 실행 파일 경로를 확인하세요. 터미널에서 CLI 설치와 로그인은 먼저 완료해야 합니다.

## 검증

- 자동 테스트 32개와 TypeScript 빌드 통과
- 실제 Claude Code / Codex 인터뷰와 출처 포함 검토 응답 확인
- `main.js`, `manifest.json`, `styles.css` 개별 릴리스 자산 제공

## 확인할 사항

macOS 데스크톱을 우선 대상으로 합니다. 실제 Obsidian의 설치, 한글 입력, 재시작 복원은 이번 BRAT 테스트에서 확인할 항목입니다. 미리보기는 LinkedIn 피드의 정확한 접힘 위치를 보장하지 않습니다.

선택한 원고·대화·자료는 CLI를 통해 해당 AI 제공자로 전달됩니다. 원고 파일 반영은 `원고 저장` 버튼으로 수행합니다.
