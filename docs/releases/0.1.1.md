# Writing Workbench 0.1.1

실사용 피드백을 반영한 화면 개선 릴리스입니다.

- 수정 제안을 수락·거절해도 읽던 위치를 유지합니다. 처리한 카드가 있는 위치를 기준으로 화면을 복원하며, 열린 이력·참고 자료와 원고 편집기의 스크롤도 유지합니다.
- 세 영역 사이의 구분선을 드래그해서 폭을 조절할 수 있습니다. 방향키도 지원하고, 두 번 클릭하거나 Home 키를 누르면 기본 너비로 돌아갑니다. 조절한 너비는 다음 실행에도 유지됩니다.
- 인터뷰·진단·수정 이유·이력·방향 메모에 Markdown 서식을 적용했습니다. 굵은 글씨, 제목, 목록, 인용, 코드, 표를 읽기 편하게 표시합니다. 변경 전후의 원문은 정확한 비교를 위해 그대로 표시합니다.
- 방향 메모는 기본적으로 읽기 화면입니다. 관점·독자가 얻는 것·근거 등 제목을 더 뚜렷하게 구분하고, 항목별 **수정 → 저장/취소**를 제공합니다. 입력창의 수동 크기 조절 핸들은 없앴습니다.
- AI 요청 직후 상단에 제공자 이름, 작업 종류, 연결 준비/실행/결과 정리 상태, 경과 시간, 중지 버튼이 표시됩니다. 실행 중에는 표시가 계속 유지되고, 완료·실패·취소 시 정리됩니다.

## 업데이트

BRAT에서 `logos1012/obsidian-writing-workbench`의 업데이트를 확인하세요. `0.1.0`으로 버전을 고정했다면 최신 버전 또는 `0.1.1`로 바꿔 주세요.

기존 원고·대화·문체 원칙 데이터 형식은 변경하지 않았습니다. 화면 너비만 별도 `state/layout.json`에 저장합니다.

## 검증

스크롤·문장 제안·메모 편집·Markdown 표시와 안전성·폭 조절·AI 실행 상태 등을 포함한 자동 테스트 47개와 TypeScript 빌드로 확인했습니다.
실제 Obsidian 화면 조작은 도구의 앱 접근 제한으로 수행하지 못했습니다. 이번 릴리스도 BRAT 검증용 사전 릴리스입니다.
