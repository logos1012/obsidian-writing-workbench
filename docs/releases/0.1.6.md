# 글결 0.1.6

- 새 글을 시작할 때 빈 파일이나 고정 작업 폴더를 만들지 않습니다. 저장 전 원고도 내부 작업 기록으로 복구할 수 있습니다.
- 원고 저장에서 자주 쓰는 여러 폴더 중 하나를 선택하고 파일명을 바꿀 수 있습니다. 다른 경로로 저장하면 이전 원고를 보존합니다.
- 설정에서 저장 폴더 목록과 새 글의 기본 모드를 관리합니다.
- LinkedIn·에세이·마케팅·일반 글쓰기 모드를 추가했습니다. 모드에 따라 방향 메모의 항목, AI 질문과 검토 기준, 미리보기가 바뀝니다.
- 기존 원고와 대화는 유지됩니다. 기존 작업은 LinkedIn 모드로 열립니다.
