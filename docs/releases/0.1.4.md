# 글결 0.1.4

제안과 원고의 위치를 연결하고 개요의 읽기 구조를 개선했습니다.

- **제안과 원고 동시 강조**: 제안 카드에 마우스를 올리면 원고의 해당 구절을 강조합니다. 화면 밖의 구절은 원고 안에서 부드럽게 찾아갑니다. 작성 중인 커서·선택 영역은 유지합니다.
- **문단·행 위치 표시**: 제안마다 위치를 표시하며 클릭하거나 키보드로 선택해도 확인할 수 있습니다. 좁은 세로 화면에서는 위치 버튼을 눌러 원고로 이동할 수 있습니다. Escape로 강조를 해제합니다.
- **수락 이후에도 정확한 위치**: 수락한 문장·거절한 원문·수락 취소를 따라 강조 위치가 바뀝니다. 삭제는 삭제된 지점을 표시합니다. 같은 변경 문장이 여러 번 생겨도 원래 구절 위치를 기준으로 구분합니다. 수동 편집으로 검토와 원고가 달라지면 위치를 추측하지 않고 다시 검토하도록 안내합니다.
- **미리보기·폭 조절 지원**: 미리보기에서도 같은 구절을 강조하며, 원고 폭을 조절하면 줄바꿈에 맞춰 표시합니다. 시스템의 동작 줄이기 설정을 존중합니다.
- **구조화된 개요**: 단계 제목·설명·하위 근거를 구분하고 여백과 들여쓰기를 정리했습니다. 한 줄에 나열된 명확한 번호 목록도 단계별로 표시합니다. 편집할 때는 원래 Markdown이 그대로 유지됩니다. AI에도 같은 개요 형식을 요청합니다.

## 업데이트

BRAT에서 `logos1012/obsidian-writing-workbench`를 **0.1.4**로 업데이트하세요.
기존 원고·작업 기록·설정 형식은 변경하지 않았습니다.

## 검증

자동 테스트 **97개**와 TypeScript 빌드 통과. 위치 계산, 수락·거절·취소, 같은 변경 문장·삭제·오래된 검토, 커서 보존, 키보드·미리보기, 강조 타이머 정리, 동작 줄이기, 개요 구조·안전한 표시·원문 편집을 검증했습니다.
실제 UI 모듈과 합성 원고를 별도 Chromium에서 실행해 밝은·어두운 테마, 긴 원고의 이동, 수락 후 카드 위치, 폭 변경에 따른 강조 위치를 확인했습니다.
실제 Obsidian 내부의 화면·한글 입력·BRAT 업데이트 인수 검증은 남아 있으며 검증용 사전 릴리스입니다.
