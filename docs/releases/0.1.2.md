# Writing Workbench 0.1.2

수락 취소와 실제 작성 흐름의 가독성을 개선했습니다.

- **수락 취소**: 수락한 제안에 취소 버튼이 나타납니다. 해당 제안만 원래 구절로 되돌리고 다시 수락·거절할 수 있습니다. 다른 수락은 유지하며 삭제 제안도 복원합니다. 이후 수동 편집이 있으면 덮어쓰지 않고 안내합니다. 취소 전 원고와 결정 기록은 이력에 남습니다.
- **메모 더블클릭 편집**: 글의 방향에서 반복된 수정 버튼을 없앴습니다. 본문을 두 번 클릭하거나 항목에 초점을 두고 Enter를 누르면 수정합니다. 저장·취소는 편집 중에만 나타납니다. Cmd/Ctrl+Enter로 저장, Esc로 취소할 수 있습니다.
- **인터뷰 → 글감 찾기**: 경험과 생각을 질문으로 풀어 주제·관점·개요를 찾는 기능임을 안내합니다. 내 답변과 AI 요약을 구분하고 이번 질문을 강조합니다. 이전 대화는 접어 볼 수 있으며 새 원고 검토 응답은 검토 탭에서 표시합니다.
- **LinkedIn 피드 미리보기**: 회색 배경, 흰 게시물 카드, 프로필·공개 범위·반응 영역을 추가했습니다. 모바일에는 하단 탐색 형태를 표시합니다. 밝은 피드 화면을 기준으로 하며 실제 게시 화면의 줄바꿈·접힘 위치와 차이가 있을 수 있습니다.

## 업데이트

BRAT에서 `logos1012/obsidian-writing-workbench`를 업데이트하세요. 버전을 고정했다면 **0.1.2**로 선택합니다.

수락 취소는 작업 사본에 반영됩니다. 연결된 Markdown 파일에도 적용하려면 **원고 저장**을 누르세요.
기존 0.1.0/0.1.1 작업 기록을 읽을 수 있으며 기존 대화·원고를 보존합니다. 새 결정 이력과 대화 구분 필드를 추가하므로 새 버전에서 저장한 기록을 이전 버전으로 읽는 다운그레이드는 지원하지 않습니다.

## 검증

- 자동 테스트 **62개**와 TypeScript 빌드 통과.
- 개별 취소, 여러 수락과 중복된 변경 문장, 삭제 복원, 수동 변경 충돌, 저장 실패 복원, 이전 기록 호환, 스크롤 유지, 키보드 편집, 대화·미리보기 표시 검증.
- 실제 UI 코드와 합성 원고를 사용하는 별도 Chromium 화면에서 밝은·어두운 테마와 좁은 창 배치 확인.
- 실제 Obsidian 안의 화면·한글 입력·BRAT 업데이트 인수 검증은 남아 있습니다. 이번 버전도 검증용 사전 릴리스입니다.
