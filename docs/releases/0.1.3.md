# 글결 0.1.3

Writing Workbench의 표시 이름을 **글결**로 바꾸고 새 글 저장 폴더 설정을 추가했습니다.

## 변경 사항

- **설정 → 글결 → 새 글 저장 폴더**에서 볼트 안의 경로를 직접 입력하거나 기존 폴더를 선택할 수 있습니다. 작업실 상단 설정에서도 동일하게 제공합니다.
- `글쓰기/LinkedIn`처럼 하위 경로를 지정할 수 있으며, 없는 폴더는 새 글을 만들 때 생성합니다. 빈 값으로 저장하면 볼트 최상위에 새 글을 만듭니다.
- 변경한 위치는 **저장**을 눌러 적용합니다. 경로가 기존 파일과 겹치거나 볼트 밖·숨김·설정 폴더를 가리키면 안내하고 적용하지 않습니다.
- 기존 원고와 연결 기록은 이동하지 않습니다. 신규 설치의 기본 폴더는 `글쓰기`이며, 기존 `Writing Workbench` 폴더가 있는 경우 그 위치를 유지합니다.
- 플러그인 목록·탭·설정·리본·명령의 표시 이름을 글결로 변경했습니다. **플러그인 ID와 저장소 주소는 유지**하므로 기존 작업 기록과 BRAT 설치를 이어서 사용합니다.
- 같은 시각에 새 글을 만들면 파일 이름에 번호를 붙여 기존 원고와 구분합니다.

## 업데이트

BRAT에서 `logos1012/obsidian-writing-workbench`를 **0.1.3**으로 업데이트하세요. 새 플러그인으로 다시 설치할 필요가 없습니다. 저장 위치는 업데이트 후 설정에서 직접 지정할 수 있습니다.

## 검증

자동 테스트 **86개**와 TypeScript 빌드를 통과했습니다. 기존 설정의 기본값·저장 위치 유지, 중첩 폴더 생성, 볼트 최상위, 경로 충돌·쓰기 실패, 중복 파일명, 설정 입력·선택·저장·오류 복구를 검증했습니다.
별도 Chromium에서 설정 UI를 렌더링해 좁은 화면 배치를 확인했습니다. 실제 Obsidian 내부의 설정·BRAT 업데이트 검증은 남아 있으며 이번 버전도 검증용 사전 릴리스입니다.
